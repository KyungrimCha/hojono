# 흔적 남기기·소식받기를 구글 시트로 받기

사이트의 **내 흔적 저장하기**와 **소식받기**에서 보낸 내용이 구글 시트에 한 줄씩 쌓이게 합니다.
시트는 **클라이언트 계정(pswjeju@gmail.com)** 에서 만들어야 데이터 주인이 클라이언트가 됩니다. 10분 정도 걸립니다.

## 클라이언트가 할 일

1. **시트 만들기**
   pswjeju@gmail.com으로 로그인한 뒤 [sheets.new](https://sheets.new)에서 새 시트를 만들고, 이름을 `HOJONO 사이트 접수`로 바꿉니다.

2. **스크립트 붙여 넣기**
   시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
   기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣은 뒤 저장(Ctrl+S)합니다.

3. **탭 만들기 (한 번만)**
   위쪽 함수 선택에서 `setup`을 고르고 **실행**을 누릅니다.
   처음에는 권한을 묻는 창이 뜹니다. 계정을 고르고, "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동 → 허용**을 누릅니다.
   시트에 `흔적 남기기`, `소식받기` 두 탭이 생기면 된 것입니다.

4. **받는 주소 만들기**
   오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(톱니): **웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   **배포**를 누르면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 전달해 주세요.
   주소를 브라우저로 열었을 때 `{"status":"ready"}`가 보이면 정상입니다.

## 전달받은 뒤 (개발 쪽)

`js/fx-objects-trace.js` 맨 위의 `SHEET_URL`에 받은 주소를 넣고 배포합니다.
주소가 비어 있으면 지금처럼 "시안 화면이라 실제로 신청되지는 않아요"로 안내하고 아무것도 보내지 않습니다.

## 알아 둘 것

- 스크립트를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 주소는 바뀌지 않습니다.
- 권한: 스크립트 맨 위 `@OnlyCurrentDoc` 덕분에 "이 시트 하나"만 다루는 권한만 요청합니다(다른 시트에는 접근하지 못함).
- 받는 정보: 흔적 남기기(남긴 시각, 인물, 장소, 한마디), 소식받기(신청 시각, 이메일, 동의). 이름·연락처는 받지 않습니다.
- 같은 이메일은 한 번만 저장됩니다. 해지 요청이 오면 `소식받기` 탭에서 그 줄을 지우면 됩니다.
- 로봇 막기: 사람 눈에 안 보이는 칸이 채워져 오면 저장하지 않고, 1분에 30건이 넘으면 잠시 받지 않습니다.
- 시트를 다른 사람과 공유할 때는 이메일이 들어 있으니 꼭 필요한 사람에게만 공유해 주세요.
- 메일을 실제로 보내기 시작할 때는 `소식받기` 탭 명단을 뉴스레터 서비스(예: 스티비)로 옮겨 쓰면 해지 링크를 자동으로 붙일 수 있습니다.
